Electric Vehicle Market Analysis Project 🚗⚡

An end-to-end data analysis project exploring the trends, growth, market adoption, and technological advancements in the global Electric Vehicle (EV) industry.

📌 Project Overview

The Electric Vehicle Market Project analyzes historical and current EV data to extract meaningful insights regarding market penetration, battery technology trends, manufacturer market share, and infrastructure readiness. This repository provides data pipelines, exploratory data analysis (EDA), visualizations, and predictive models to understand the EV landscape.

🎯 Objectives

Analyze EV sales and adoption rates across different regions and years.

Compare Battery Electric Vehicles (BEVs) vs. Plug-in Hybrid Electric Vehicles (PHEVs).

Evaluate leading manufacturers (OEMs) and popular vehicle models.

Examine key technical metrics such as electric range, battery capacity, and pricing.

Forecast future EV market trends using machine learning models.

🛠️ Tech Stack & Tools

Programming Language: Python 🐍

Data Analysis & Manipulation: Pandas, NumPy

Data Visualization: Matplotlib, Seaborn, Plotly

Machine Learning (optional): Scikit-Learn

Environment: Jupyter Notebook / Google Colab

🚀 Getting Started

Follow these instructions to set up and run the project locally.

Prerequisites

Make sure you have Python 3.8+ installed on your system.

Installation

Clone the repository:

git clone https://github.com/Aryan-Parashar-tech/Electric-vehicle0market-project
cd Electric-vehicle0market-project


Create a virtual environment (optional but recommended):

python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate


Install dependencies:

pip install -r requirements.txt


Launch Jupyter Notebook:

jupyter notebook
